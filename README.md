# Платформа для публикации платного контента

## Описание проекта

Эта платформа предназначена для публикации и обмена контентом. Пользователи могут создавать посты, делиться своими знаниями, учиться. Платформа включает в себя функционал подписки, а также систему управления пользователями.

## Функционал

- **Создание и управление постами**: Пользователи могут создавать, редактировать и удалять свои посты.
- **Категории постов**: Посты могут быть отнесены к различным категориям, таким как "Мир", "Наука", "Культура" и т.д.
- **Подписка на контент**: Пользователи могут подписываться на платные материалы и получать доступ к эксклюзивному контенту.
- **Уведомления**: Пользователи получают уведомления по электронной почте о различных событиях, таких как удаление поста.
- **Тестирование и отладка**: В проекте реализованы тесты для проверки функционала.
- **Поддержка Celery**: Для обработки фоновых задач, таких как отправка уведомлений.
- **Docker и Nginx**: Проект упакован в контейнеры Docker и развернут с использованием Nginx.

## Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ваш-репозиторий.git
   cd ваш-репозиторий

2. **Создайте виртуальное окружение и активируйте**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте venv\Scripts\activate
   
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   
4. **Настройте базу данных**:
   - Убедитесь, что настройки базы данных в settings.py корректны.

5. **Создайте миграции и примените их**:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   
6. **Запустите сервер**:
   ```bash
   python manage.py runserver
   
## Развертывание с помощью Docker

1. Убедитесь, что у вас установлен Docker
2. Скопируйте файл `.env.example` в `.env` и заполните его вашими данными.
3. В корне проекта выполните команду:

   ```bash
   docker-compose up -d --build
   ```
4. После успешного запуска вы сможете проверить работоспособность сервисов:

- Бэкенд: Перейдите по адресу http://localhost:8000
- PostgreSQL: Подключитесь к базе данных на localhost:5432 с использованием указанных в .env данных.
- Redis: Используйте redis-cli для подключения к localhost:6379.
- Celery: Логи можно просмотреть через docker-compose logs или подключившись к контейнерам.
### Остановка проекта
Чтобы остановить проект, выполните:
```bash
docker-compose down
````
